# AMItienda

Página de demostración con un estilo de tienda clásica. Incluye:

- Fondo con efecto de pared de ladrillo.
- Toldo superior con franjas bicolor.
- Catálogo lateral de categorías.
- Vitrina principal con 12 espacios para tiendas.
- Letrero de servicios ubicado fuera de la tienda.
- Barra de navegación con enlaces a **Nosotros**, **Precios** y **Cursos gratuitos**.

Cada sección se encuentra en archivos individuales para facilitar su edición.
